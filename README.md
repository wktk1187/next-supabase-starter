# 🚀 Next.js + Supabase Starter Template

## ENGLISH

A modern, production-ready starter template using:

- ✅ Next.js (App Router)
- ✅ Supabase (Auth, RLS, PostgreSQL)
- ✅ TypeScript + ESLint + Prettier + Husky
- ✅ GitHub Actions for CI/CD
- ✅ Zod validations
- ✅ Centralized error handling (AppError)
- ✅ Authentication state management (AuthContext)
- ✅ Ready-to-deploy with Vercel

### 🔧 Quick Setup

```bash
git clone https://github.com/YOUR_NAME/next-supabase-starter.git
cd next-supabase-starter
npm install
cp .env.example .env.local
npm run dev
